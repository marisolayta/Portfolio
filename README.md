# Marisol Ayta — Portfolio

A soft pink, dark-themed personal portfolio (local preview only for now).

## Run locally

```bash
cd "D:\Marisol Ayta"
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Customize

Edit **`src/data/portfolio.js`** for name, bio, personal info, education, skills, and projects.

Add her photo as **`public/profile.png`** (round crop works best). Until then, a pink placeholder shows automatically.

## Deploy later

When ready for GitHub Pages, create a new repo and we can add the same deploy setup as your portfolio.
